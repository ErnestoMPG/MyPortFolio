### Run locally

Install a Node.js version supported by the installed Vite release, then run:

```sh
npm install
npm run dev
```

Use `npm run build` to create a production build and `npm run preview` to preview it locally. The build is configured for the `/MyPortFolio/` GitHub Pages project path.
