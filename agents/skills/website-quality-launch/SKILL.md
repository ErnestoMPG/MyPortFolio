# Website quality and launch

1. Inspect scope, repository changes, checks, deployment path, and public content. Review semantics, keyboard access, focus, accessible names, contrast, alternatives, responsive behavior, zoom, and reduced motion.
2. Review assets, loading, metadata, links, project base paths, privacy, secrets, dependencies, external services, and content accuracy. Report performance measurements only when actually measured.
3. Run available builds, tests, and browser checks; distinguish automated results from manual checks and untested areas. Report prioritized findings with evidence and reproducible steps.
4. Provide a launch checklist, post-launch smoke tests, and rollback considerations. Obtain explicit approval before deployment or public account changes.
