# Remotion video workflow

1. Establish output, duration, aspect ratio, assets, and existing stack. Use Remotion only for a requested code-driven workflow and with approval for dependencies; check current official documentation and licensing.
2. Plan composition, frame rate, timing, typography, captions, audio, readability, and safe areas. Derive animation timing from frames and follow installed-version conventions.
3. Respect media rights, protect secrets, run available checks, preview and render when possible, and report limitations.
