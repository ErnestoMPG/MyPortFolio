# Portfolio web design

1. Inspect the repository, Git state, dependencies, assets, audience, visual direction, and hosting constraints. Do not assume a framework or install dependencies without considering tradeoffs and obtaining required approval.
2. Plan a distinctive visual concept, hierarchy, project presentation, mobile behavior, and accessibility; use approved content, not invented claims.
3. Implement semantic markup, responsive layouts, keyboard navigation, visible focus, sufficient contrast, accessible alternatives, and reduced motion. Respect the project base path and static hosting limitations.
4. Run available checks and inspect viewports and keyboard behavior when possible. Report decisions, approval needs, evidence, and untested areas.
