# YouTube publishing

1. Establish the audience, content, objective, and tone. Never claim to have watched footage or measured performance without evidence.
2. Offer accurate titles and thumbnail concepts, a description using supplied links, and a restrained call to action. Do not invent URLs, claims, or sponsorship disclosures.
3. Use supplied timings for chapters or mark estimates; recommend reviewed captions, intelligible audio, and a mobile preview. Check current platform requirements when exact specifications matter.
4. Obtain confirmation before publishing or changing a public account.
